## Introduction

The `markov` R package provides tools for statistical inference on
finite, discrete-time Markov chains and the analysis of system
reliability.

### Key Features

- Simulation and estimation of Markov chains.
- Transition probabilities and stationary distributions.
- Reliability, availability, and maintainability measures.
- Hypothesis testing and uncertainty estimation.

## Installation

You can install the release version of `markov` from CRAN by running the
following line of code:

``` r
 install.packages("markov")
```

You can install the development version of `markov` from github by
running the following line of code:

``` r
 devtools::install_github("thechibo/markov")
```

More details can be found in the [markov Github
repository](https://github.com/thechibo/markov "markov Github repository").

## Documentation

Detailed documentation, along with reproducible examples, can be found
